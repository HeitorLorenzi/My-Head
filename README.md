# My-Head ⚡

Projeto baseado na atividade prática de **GitFlow**, **Pull Requests** e Deploy contínuo no **GitHub Pages**, utilizando os arquivos base de animação com **GSAP** da aula anterior.

## 🌐 Demonstração Online
O projeto está publicado e funcional em:
👉 **[https://heitorlorenzi.github.io/My-Head/](https://heitorlorenzi.github.io/My-Head/)**

---

## 🌿 Estrutura do GitFlow
O repositório foi organizado no modelo padrão GitFlow:

``text
main (Versão estável / Publicada no GitHub Pages)
 │
 └── develop (Integração contínua)
      │
      └── feature/personalizar-home (Personalização da página inicial e controles GSAP)
``

### 📋 Histórico de Commits Semânticos:
1. chore: adiciona estrutura inicial do projeto (Arquivos base da aula anterior)
2. eat: adiciona cabeçalho da página (Navbar responsivo com navegação)
3. style: melhora layout da página principal (Animação centralizada, controles interativos GSAP e seção Sobre)
4. eat: adiciona links de contato (Seção de contato, redes sociais e rodapé)
5. docs: adiciona template de pull request (Configuração de template em .github/PULL_REQUEST_TEMPLATE.md)

## 🚀 Como Testar Localmente
1. Clone este repositório:
   ``bash

   ``
2. Acesse o diretório:
   ``bash
   cd My-Head
   ``

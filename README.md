# My-Head ⚡

Projeto desenvolvido como atividade prática sobre **GitFlow**, criação e integração de **Pull Requests** e deploy contínuo utilizando o **GitHub Pages**.

## 🌐 Demonstração Online
O projeto está publicado e acessível em:
👉 **[https://heitorlorenzi.github.io/My-Head/](https://heitorlorenzi.github.io/My-Head/)**

---

## 🌿 Fluxo GitFlow Utilizado

O desenvolvimento seguiu o modelo GitFlow proposto:

``text
main (Versão estável / Produção / GitHub Pages)
 │
 └── develop (Integração de funcionalidades)
      │
      └── feature/personalizar-home (Desenvolvimento e personalização da página)
``

### 📋 Histórico de Commits:
1. chore: adiciona estrutura inicial do projeto
2. eat: adiciona cabeçalho da página
3. style: melhora layout da página principal
4. eat: adiciona links de contato
5. docs: adiciona template de pull request

## 🚀 Como Executar Localmente
1. Clone o repositório:
   ``bash
   git clone https://github.com/HeitorLorenzi/My-Head.git
   ``
2. Acesse a pasta do projeto:
   ``bash
   cd My-Head
   ``
3. Abra o arquivo index.html em qualquer navegador web.

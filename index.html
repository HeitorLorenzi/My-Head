Sobre o Projeto & Desenvolvedor

Desenvolvido por Heitor Lorenzi para praticar o fluxo GitFlow, integração de Pull Requests e deploy automatizado no GitHub Pages.

O projeto integra HTML5, estilos CSS personalizados, Bootstrap 5 e a biblioteca de animações GSAP (GreenSock).
